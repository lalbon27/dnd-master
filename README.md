# D&D Master

Локальный веб-стол для настольной D&D-партии: генерация подземелий и персонажей, мастер на базе бесплатного ИИ, озвучка мастера и голосовые ответы игроков.

## Запуск

```bash
npm install
cp .env.example .env   # впиши бесплатный GROQ_API_KEY (console.groq.com/keys, без карты)
npm run dev
```

При первом запуске сгенерируй сертификат для HTTPS (нужен для доступа к микрофону на телефонах игроков — браузеры блокируют его на обычном http, кроме localhost):

```bash
mkdir certs
openssl req -x509 -newkey rsa:2048 -nodes -keyout certs/key.pem -out certs/cert.pem -days 825 \
  -subj "/CN=dnd-master" -addext "subjectAltName=DNS:localhost,IP:<твой-локальный-IP>,IP:127.0.0.1"
```

(уже сгенерирован для IP `192.168.1.77` — если IP компьютера сменится, перегенерируй с новым `subjectAltName`)

Сервер поднимется на `https://localhost:3000` и слушает `0.0.0.0`, так что игроки в той же Wi-Fi сети открывают `https://<твой-локальный-IP>:3000` с телефона. Браузер покажет предупреждение "соединение не защищено" (сертификат самоподписанный) — нужно один раз нажать "Дополнительно → Перейти на сайт".

- `/dm.html` — пульт управления (не роль мастера!): генерация подземелья, создание/удаление персонажей, общая хроника, озвучка реплик мастера вслух (чекбокс 🔊, браузерный TTS). Рассказывает историю только ИИ — ручного ввода реплик "от мастера" в интерфейсе нет.
- `/player.html` — экран игрока: выбор своего персонажа, лист персонажа, отправка действий текстом или голосом (кнопка 🎤 — запись, распознавание через Whisper, текст сразу уходит мастеру). Кнопка «✨ Создать нового героя» запускает анкету из 3 вопросов (влияют на класс, черту характера и девиз) и опционально селфи с камеры — оно остаётся только на этом сервере и показывается рядом с портретом, никуда не отправляется.

### Фазы кампании

Кампания идёт по двум фазам: **«Подготовка»** (`setup`) и **«Игра»** (`playing`). Пока идёт подготовка, игроки создают героев, а у них на экране вместо хроники и поля хода — зал ожидания. Мастер на `/dm.html` видит счётчик созданных персонажей и кнопку **«▶ Начать игру»** (активна, если создан хотя бы один герой); по нажатию мастер сам придумывает вступительную сцену и с этого момента экраны игроков открывают хронику и поле для хода. `POST /api/action` и `/api/action-audio` до старта игры отвечают `409`.

Без `GROQ_API_KEY` мастер отвечает шаблонными фразами вместо живой генерации, а голосовой ввод не работает — остальной функционал (карты, персонажи, хроника, текстовые действия) работает как есть.

Если вписать `CF_ACCOUNT_ID` и `CF_API_TOKEN` (бесплатный Cloudflare Workers AI, см. `.env.example`), портрет персонажа будет рисоваться на основе селфи игрока (модель FLUX.2 klein, фото уходит напрямую в запрос, без публичного хостинга) — иначе портрет генерируется только по текстовому описанию, без лица.

## Статус / что дальше

- ✅ Процедурная генерация подземелий (комнаты + коридоры, теги: монстр/ловушка/сокровище/босс), тактическая карта рисуется настоящими тайлами (пол/стена) прямо в браузере на `<canvas>`, с цветовой перекраской под одну из 6 тем — без ИИ и сети, мгновенно и точно по слою
- ✅ Атмосферная заставка локации (Pollinations, бесплатно) — живописная иллюстрация сцены по теме подземелья, показывается и мастеру, и игрокам для погружения (отдельно от тактической карты)
- ✅ Процедурная генерация персонажей (5e-статы, внешность, снаряжение)
- ✅ Мастер на бесплатном Groq (`openai/gpt-oss-120b`) с текстовым фолбэком без ключа
- ✅ Озвучка мастера вслух (браузерный Web Speech API, экран `/dm.html`)
- ✅ Голосовые ответы игроков (запись в браузере → бесплатный Groq Whisper → текст мастеру)
- ✅ Портреты персонажей (бесплатная генерация через image.pollinations.ai по описанию внешности, без ключей)
- ✅ Анкета из 3 вопросов перед созданием героя (влияет на класс/характер/девиз), настоящее имя игрока → мастер придумывает созвучное фэнтезийное имя (тоже через Groq)
- ✅ Портрет по селфи: Cloudflare Workers AI (FLUX.2 klein) переносит лицо в фэнтези-портрет, бесплатно (~10к нейронов/день, без карты) — без ключей CF просто остаётся обычный сгенерированный портрет без лица, всё продолжает работать
